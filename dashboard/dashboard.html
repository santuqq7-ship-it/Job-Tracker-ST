第一次导入 · iPhone / iPad

        
    
          
  1. 把导出的 .ics 文件发到手机（微信「文件传输助手」、AirDrop、邮件附件都行）。
    2. 
          
  2. 手机上点开这个文件 → 右上角「分享/…」→ 用「日历」打开。
    3. 
          
  3. 系统问你加到哪个日历时，点「新建日历」，建一个叫「投递管家」的日历再存进去。
    4. 
          
  4. 完成。到点由系统日历提醒（提前 1 天 + 提前 1 小时各一次）。
    5. 
        


        
第一次导入 · Android（小米 / 华为 / OPPO / vivo / 三星）

        
    
          
  1. 把 .ics 文件存到手机：微信里点开文件 → 右上角「…」→ 用其他应用打开 → 选「日历」。
    2. 
          
  2. 部分机型要手动导入：日历 → 设置 → 导入/导出 → 从文件导入；导入时若能选日历，同样新建一个「投递管家」日历。
    3. 
          
  3. OPPO / vivo / 荣耀 的自带日历可能没有导入入口，可用系统「文件」App 直接打开该 .ics，或用 Google 日历导入。
    4. 
        


        
之后更新（改了截止时间 / 加了新岗位 / 删了岗位）

        
    
          
  1. 重新点上面的「导出日历文件」，拿到一份新的 .ics（文件名带时间，和上一份不同）。
    2. 
          
  2. 先把手机里那个「投递管家」日历整个删掉（iPhone：日历 App 底部「日历」→ 点它右边的 ⓘ → 删除日历；安卓：日历 → 设置 → 找到该日历 → 删除）。
    3. 
          
  3. 再按上面的步骤导入新文件，仍然建/选「投递管家」日历。
    4. 
        


        

          为什么建议单独建一个「投递管家」日历？
          ① 本工具导出的提醒全部集中在这一个日历里，绝不碰你自己的其他日程；
          ② 更新时删掉这一个日历就干净重来，不影响任何别的日程。
        

        

          为什么不直接覆盖导入、非要先删日历？
          文件里每个截止节点都有固定编号，设计上重新导入应当是「更新同一件事」而不是新增。
          但实测各手机系统并不可靠：iOS 有时会静默跳过对已有事件的更新，
          部分安卓日历（含 AOSP 血统的）会无条件新增一条，导致同一件事出现两条。
          「先删日历再导入」在所有机型上都成立，所以默认按这个来。
        

        

          「导出清空文件」是干什么的？
          它生成一份把所有旧提醒标记为「已取消」的文件，理论上导入后旧提醒会消失 ——
          实测 Google 日历、iOS 日历、多数安卓自带日历都不认这个标记，只有 Mac 上的「日历」App 认。
          所以它只是个辅助手段；不确定时请走上面「删日历 → 重新导入」那条路。

📅 手机日历订阅

          
把全部截止节点同步到手机自带日历，原生提醒、无需安装任何 App；改了时间手机端会自动更新。

          

            
            
          

          

            iPhone 添加方法
            设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历 → 粘贴上面的地址 → 存储
          

          

            安卓添加方法（华为 / 小米 / OPPO / vivo）
            打开系统「日历」→ 找「订阅管理 / 添加订阅 / 日历订阅」→ 粘贴地址。

            若机型没有该入口，可安装任意支持 ICS 订阅的日历 App（如 Outlook）。
          

          
不想（或还没）部署服务端？点面板顶栏的「📅 手机日历」导出 .ics 文件，
            发到手机点开导入系统日历，一样有原生提醒。

            更新提醒时：重新导出一份，先把手机里那个「投递管家」日历整个删掉再导入 ——
            这是唯一在所有机型上都成立的做法（点开弹窗里有 iPhone / 安卓的分步说明）。

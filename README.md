# 投递状态管家 v1.27.0

在岗位详情页点一下，把公司、岗位、投递链接与 JD 存下来；之后在一个面板里跟踪每条投递的
状态、面试轮次、截止节点与面经。数据默认只存在本机，配置同步后可在手机上看、到点收到提醒。

---

## 一、安装（约 1 分钟）

1. 把本文件夹放在一个**不会被清理**的位置（安装后这个文件夹要一直留着，不要删除或移动）
2. Chrome 地址栏打开 `chrome://extensions`（Edge 是 `edge://extensions`）
3. 打开右上角的「开发者模式」
4. 点「加载已解压的扩展程序」，选择**本文件夹**（含 `manifest.json` 的那一层）
5. 点浏览器工具栏的拼图图标，把「投递状态管家」固定到工具栏

## 二、开始使用

- 在**岗位详情页**点扩展图标 → 核对公司 / 岗位 / 链接 / JD → 「保存投递」
  - 「识别来源」会写明公司名与岗位名各自是从哪里认出来的；识别不对可直接在表单里改
  - 若管理员给了服务端地址与注册口令，下面还会有一行 AI 建议（把页面上更完整的岗位名挑出来
    自动填上，旁边有「撤销」；正在编辑的字段不会被改动）。这一行只认**注册口令** ——
    只填了同步口令不会有它（同步口令管的是记录上不上云，两件事）
  - **也可以一个口令都不要**：设置里「配置模型」填上你自己的模型接口，AI 那行就整条走
    你自己的模型（详见「数据与隐私」最后一节）
  - 抓不到内容的页面（登录墙、懒加载等）会提示手动填写，填完一样能保存
  - 表单里的「企业性质」与「行业赛道」可以留空。公司名一填好，本机就按常见企业库与名称规则
    自动带一次（不联网）；有 AI 建议时还会再问一次模型，回来的值只补还空着的那栏，
    你自己改过的一律不动
  - 本机认错了（比如把某家公司的行业认成了「交通/物流」）就点两栏下面的「🤖 AI 再认一次」：
    按公司名重新问一次模型，**覆盖本机填的值**、并跳过本机缓存，但**不碰你自己选过的那栏**。
    自动填的那几条路只填空格，纠正不了已经填错的值 —— 这个按钮就是为这种情况准备的
- 点「打开面板」查看全部投递：状态、面试轮次、截止节点、JD 全文、搜索与筛选、看板视图
- 卡片上的「央企 · 能源/化工」就是上面那两栏，工具栏的下拉可以按「央企」「汽车/新能源」
  这类维度筛；老记录没填过的显示「类型待确认」，点工具栏「🏷 识别企业类型」可以一次补齐 ——
  先在本机跑一遍（不联网），剩下认不出的才问模型，弹窗里先给预览、点「应用」才写入，
  而且只填空着的那栏，写错了有「撤销本次识别」
- 每完成一轮笔试或面试，在卡片上点「🎤」按轮次记下题目与复盘（长文可搜索）

## 三、多设备同步与手机端

同步依赖管理员部署的服务端，地址与口令由管理员提供 —— **口令即身份，不要转发给他人**。

1. 面板右上角「⚙ 设置」→ ☁ 云同步 → 填入**服务端地址**与**同步口令** → 勾选「启用云同步」→ 保存
2. 点「连接测试」，显示已连接即配对成功；第二台设备填同一串口令即可自动合并记录
3. 手机端：打开管理员给的**手机页地址** → 把电脑端「⚙ 设置 → 📱 手机端」里的**配对串**
   复制、发送到手机 → 在手机页粘贴 → 「解析并填入」→「开始使用」
4. 手机页建议「添加到主屏幕」，之后像 App 一样直接点开

## 四、手机提醒（二选一，都不用装 App）

- **手机日历**：面板顶栏「📅 手机日历」导出 `.ics` 文件 → 发到手机点开导入系统日历。
  改了截止时间就重新导出一次；更新前**先把手机里那个「投递管家」日历整个删掉再导入**
  （各机型的详细步骤在导出弹窗里）
- **服务端推送**：设置 → 📱 手机提醒 → 选 PushPlus（普通微信）/ Bark（iPhone）/ 通用 Webhook
  （飞书、钉钉、企业微信）→ 按提示填 token → 「发送测试推送」，收到即配置成功

## 五、已有表格怎么办

已经在飞书 / 腾讯文档 / WPS / Excel 里记着投递表的不必手抄：面板顶栏「导入表格」→ 在表格里
连表头一起选中、复制 → 回到面板粘贴 → 预览确认。规则是**以表格为准**：表里写了的值覆盖本机，
表里空着的保留本机原值，不满意可点报告里的「撤销本次导入」整份回滚。也可直接拖入 `.csv` / `.tsv` 文件。
表里若有「企业性质 / 性质 / 单位性质」与「行业 / 行业赛道 / 赛道」两列，或只有一列「企业类型」
（写成「央企 · 能源/化工」这样），导入时会自动拆成那两栏 —— 认不出的段落留空，不会瞎猜。

面板顶栏的「导出 JSON」是**完整备份**（换电脑、重装都靠它：导出后在新设备「导入 JSON」，
是合并不是覆盖）；「导出 CSV」用于在表格软件里查看。

## 六、数据与隐私

- 记录默认**只存在本机浏览器里**。在 `chrome://extensions` 里「移除」本扩展会一并删除数据，
  建议定期用面板「导出 JSON」备份（扩展**不会**自己往下载目录写任何文件，导出只在你点那个
  按钮时发生；备份文件放哪儿由你决定，需要时用「导入 JSON」找回）
- 启用云同步后：记录（含 JD 全文）会存到**管理员部署的服务端**，仅凭口令访问，不收集邮箱、
  手机号等任何账号信息
- 开启「AI 兜底识别」、且设置里填了服务端地址与**注册口令**后（**不必填同步口令、不必启用云同步**；反过来只填同步口令也不会有建议 —— 同步口令只负责云端同步）：点开扩展时会把这**一页的地址、网页标题、页面上抓到的候选文本**
  经服务端转交模型识别一次；**不含整页 HTML，也不含 JD 全文、备注或其他记录**。
  识别结果只缓存在本机，不上传、不与他人共用
- 面板里点「🏷 识别企业类型」问模型时，发过去的只有**公司名**（每批最多 12 家，同一家公司
  只问一次，之后走本机缓存）；同样不含 JD、备注等任何其他内容。手动点「🤖 AI 再认一次」
  也只发这一个公司名，区别是它**绕过缓存**、必定重新问一次（同一家公司多问一次就多花一次额度）
- 不想用上面这个模型也行：面板「⚙ 设置 → AI 兜底识别 → 配置模型」里填**你自己的模型**
  （接口地址、API Key、模型名称，任何 OpenAI 兼容的接口都可以），勾上「启用」之后，
  上面这些 AI 功能**全部改走它**、**一个口令都不需要**，请求由这台电脑的浏览器直接发出。
  那个 Key 只存在这台电脑里，不进记录、不参与云同步、也**不会写进「导出 JSON」的备份**；
  填了地址之后浏览器会问一次「是否允许访问该地址」，不许就不发请求。你自己的模型没调通时
  **只会报错，不会悄悄改回管理员的模型**（免得你以为走的是自己的、其实在花那边的额度）

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 公司 / 岗位识别不准 | 直接在表单里改。「识别来源」那一行写明每个字段的来源；面板里还能用「⇄ 交换公司名与岗位名」一键对调 |
| 企业类型识别不准 | 在卡片的「编辑」弹窗里改（下拉里没有合适选项就选「＋ 自定义…」自己写）；本机企业库/名称规则认错了就点编辑弹窗里的「🤖 AI 再认一次」按公司名重判一次（覆盖本机填的值、绕开本机缓存，但你手动选过的那栏不会被它动）。手改过的值也不会被批量识别覆盖 |
| 点图标没反应、面板空白 | 在 `chrome://extensions` 里对本扩展点「重新加载」；仍不行请确认扩展文件夹还在原位 |
| 扩展更新了怎么升级 | 用新文件夹替换旧的，然后在 `chrome://extensions` 里点「重新加载」——数据不会丢 |
| 手机页还是旧界面 | 手机页 ⚙ 设置 → 「刷新到最新版」 |
| 换了一台电脑 | 旧设备「导出 JSON」→ 新设备装好扩展后「导入 JSON」，两台记录会并在一起 |
